Custom room program

Define the room program and target clear areas. The solver searches partitions and adds circulation. A combined living/dining/kitchen is added only if the program has no Living room. Clear areas must stay within 25% of the target and within studio room-type limits. Exact dimensions and adjacency are not guaranteed.

New concepts use a single-storey constraint solver. North is assumed at the top. Footprint dimensions run between exterior wall centrelines; the outside extent adds 0.30 m in each direction. Clear room dimensions exclude assumed 0.30 m exterior and 0.12 m interior walls. No site setbacks are checked. Furniture access clearances, regulations and professional review remain unverified.

Draw a room layout on a grid

Generate or open a house first, then edit its actual geometry here. Select rooms, draw a full-span partition to create a new room, or select two matching adjacent rooms to merge them. Snapping and dimensions are shown in metres; accepted changes update the 2D plan, 3D model, validator, revision and exports together. Without a generated model, the canvas remains a clearly labelled sketch only.

Grid snap: 0.25 m. Select a room, then choose Draw partition for a divider or Draw closed boundary to recognize a rectangular room from a closed wall loop. Closed boundaries must meet one complete side of the selected room. Shift-click a second room to merge two adjacent rooms of the same type. Wall dragging in the plan resizes shared boundaries.
